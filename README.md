# Servoshakti FieldForce

Multi-company OEM, warranty & field-service partner network platform.

- `backend/`  Express + MongoDB API (shared by all panels/apps)
- `frontend/` Web panels: OEM, Vendor, Servoshakti Admin (module per role)
- `Apps/EngineerApp/`  React Native engineer app / tracker
- `Apps/CustomerApp/`  React Native customer app (product passport, AI complaint)
